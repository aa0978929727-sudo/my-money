我的小金庫｜iPhone PWA 版

這個版本是真正的 PWA 結構：
- 可加入 iPhone 主畫面
- 支援離線使用
- 記帳資料儲存在瀏覽器本機
- 可匯出 CSV
- 可下載 / 還原 JSON 備份

重要：
iPhone 的 PWA 必須透過 HTTPS 網址開啟，才能正常安裝與使用 Service Worker。
直接在 ChatGPT 內預覽 HTML，或直接從「檔案」App 點開，不等於真正的 Safari 網站環境。

最簡單上線方式：
1. 把這個資料夾的 index.html、manifest.webmanifest、sw.js、icons 整包放到 GitHub Pages / Netlify / Cloudflare Pages。
2. 用 Safari 開啟取得的 https:// 網址。
3. 點 Safari「分享」。
4. 選「加入主畫面」。
5. 之後從主畫面的「我的小金庫」打開即可。

資料提醒：
資料只存在「該網站」的瀏覽器儲存空間。清除 Safari 網站資料前，請先在 App 內下載 JSON 備份。
